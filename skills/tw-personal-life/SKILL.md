# 台灣個人日常生活官方查法與範本

這個技能告訴你：日常生活裡常要提醒的事，**去哪個官方頁查、穩定的規則是什麼、哪裡會變要再查、可以直接套的表格長什麼樣子**。

你給的是**整理與提醒，不是醫療、稅務、法律或投資意見**。遇到要判斷的個案，一律寫「請洽○○」。

**查詢紀律**（全技能適用）
- 本技能所有網址的查詢日都是 **2026-11-07**。每一條標「已核對」的，都是當天實際打開、內容就在那一頁。標「未查證」的，是打不開、頁面沒寫，或只在搜尋摘要看到。
- 引用前**先打開技能列的網址再核對一次**，附那一頁和你的查詢日期；頁面改了就照新頁寫，並說明和技能不同。
- 會變的數字（費率、手續費、罰鍰、補助、名額、當年截止日）**只寫去哪查**，不從本技能抄。
- 不登入、不送出表單、不代繳、不代訂、不代退訂、不代申請；只給步驟，由使用者自己按。
- 不記身分證字號、護照號碼、卡號、帳號、密碼、驗證碼、完整地址。使用者貼出來時寫成 ***，並提醒不用給。

### 4. 步驟：使用者說「我的○○快到期了」
1. 問證件種類和到期日（不要問號碼）。
2. 打開上表該證件的官方頁，核對資格、管道、要帶什麼。

### 5. 常見錯誤
- 把駕照寫成「75 歲才要換」：現行規定是滿 70 歲就要體檢與講習。
- 以為一般駕照上印的日期還有效：115/5/31 起一般普通駕照免定期換照，但職業駕照、高齡仍要換。
- 居留證寫成「到期前 30 日內」：移民署頁是到期前 3 個月內。
- 護照效期只看「還沒過期」：出國前要看目的地要求的剩餘效期。
- 把規費、罰鍰金額抄進總表：會變，只寫「見官方頁」。
- 在總表記證號或護照號碼。

- 寫死選舉日期：只寫已核對那一場，其他場次看中選會公告。
- 替使用者用自然人憑證登入申請：一律由使用者自己操作。

### 1. 晨間簡報（每天固定一則）

**欄位順序**（照生活總管卡片）：
1. 天氣與要帶的（中央氣象署居住縣市今日預報；有警特報放第一行）

早安，11/7（六）

```
早安，11/8（日）
天氣：臺北 19～24 度，多雲，不用帶傘
今天沒有行程、到期帳單和提醒。
```

**有警特報時**：第一行寫「【特報】氣象署發布○○特報（影響○○），附連結」；颱風天加一行「停班停課：見人事總處頁，○○縣市尚未公布／已公布○○」。

**簡報規則**
- 已達提醒次數的不放；放了的記進 提醒紀錄.csv。
- 金額照 帳單.csv 寫，沒有就寫「待補」。

規則：

### 3. 間隔複習排程（學習方法，非官方規定）

- 間隔是常見做法（標「建議」），使用者可自己調；某次忘了，就從上一級重來。
- 寫進 學習計畫.md 的「複習表」：內容、首次學習日、下次複習日、第幾次。

```
# 學習計畫

- 國資圖電子書平台（數位借閱證）

| 內容 | 首次學習日 | 下次複習日 | 第幾次 |
## 本週進度
```

### 5. 步驟：使用者說「想學○○、有沒有免費資源」
1. 問主題、每週時數、要不要證書。
2. 先找公部門資源：圖書館電子書、職訓課程、磨課師；每個都打開內容頁確認資格。
3. 補助比例、名額、開課日只寫「見官方頁」，不抄。
4. 報名、申請借閱證由使用者自己做。

### 6. 常見錯誤
- 把「國圖 e 卡」當正式名稱：官方頁沒有這個名稱，寫「國家圖書館線上辦證」。
- 以為數位借閱證能借實體書：國資圖數位借閱證不能。
- 寫死職訓補助：會變，附勞動部頁。
- 連續天數自己補「完成」。
