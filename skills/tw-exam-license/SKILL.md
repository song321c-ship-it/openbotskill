# 國家考試與證照（考選部＋技能檢定）

這個技能教你：**去哪查、穩定規則是什麼、每年會變的去哪找、怎麼排讀書計畫、哪裡容易錯**，並附可直接套的表格。

你給的是**考試資訊整理與讀書規劃，不是資格審查結論**。學歷是否「相當科系」、國外學歷能不能用、經歷算不算，一律寫「以考選部（或技能檢定中心）審查為準，請洽承辦單位」。

**查詢紀律**（全技能適用）
- 本技能所有網址的查詢日都是 **2026-11-07（民國 115 年 11 月 7 日）**。標網址的內容都是當天實際打開、在那一頁看得到。標「未查證」的是頁面沒寫、內容在 PDF 附件沒逐項核對，或只在搜尋摘要看到。
- 引用前**再打開技能列的網址核對一次**，附那一頁和查詢日期；頁面改了就照新頁寫，並說明和技能不同。
- 每年會變的（報名日期、考試日期、需用名額、報名費、技檢梯次與職類）**只寫去哪查**。本技能列出的 116 年日期，是官方頁明寫 116 年的「預定」日期；115 年的費用與梯次只當格式範例。
- 「預定」和「公告」要分清楚：考試期日計畫表是暫定，**以考試公告為準**。
- 報名、繳費、疑義、複查、閱覽試卷、退費都要**本人登入**操作。代理只整理資料、算期限、給草稿，不登入、不送出。
- 不記身分證字號、出生日期、准考證號、帳號密碼。使用者貼出來時寫成 ***。

## 二、國家考試的種類與差別

### 1. 兩大類

| | 公務人員考試 | 專門職業及技術人員考試（專技） |
|---|---|---|
| 目的 | 取得公務人員任用資格 | 取得執業資格（律師、會計師、技師、醫事人員等） |
| 等級 | 高等考試分一、二、三級；普通、初等；另有特種考試一～五等（考試法 6） | 高等、普通二等；可限期舉行特種考試（專技考試法 3） |
| 結果 | **錄取**：依用人機關需用名額決定正額，可增列增額（考試法 3） | **及格**：科別及格、總成績及格、到考人數一定比例及格，三選一或併用（專技考試法 16） |
| 之後 | 要**分配訓練**，訓練及格才發及格證書、分發任用（考試法 21） | 發及格證書；部分類科要先訓練或學習（專技考試法 18）；**執業另依各職業法登記** |
| 轉調 | 高普初考及格服務 3 年內、特考 6 年內，不得轉調原分發機關以外（考試法 6；細則 7） | 無 |

條文頁：考試法第 3 條 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=R0030001&flno=3 、第 6 條 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=R0030001&flno=6 、專技考試法第 16 條 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=R0040001&flno=16 。

### 2. 考試代碼怎麼讀
期日計畫表上的代碼前三碼是民國年，例如 116010＝116 年公務人員初等考試、116080＝116 年高考三級暨普考（期日計畫表原文）。同一代碼可能包含多個考試（例如 116040 同時有關務、身心障礙、國軍上校以上轉任），報名時要選對考試名稱。

### 3. 常見錯誤
- 把「錄取」和「及格」混用。公務人員考試錄取後還要訓練，訓練沒過就沒有及格證書。
- 以為特考和高普考一樣 3 年就能調動。特考是 6 年。
- 以為專技考試及格就能執業。執業要另外向主管機關申請證書、執業登記，多數還要加入公會（見八章）。

### 2. 查法步驟
1. 先問清楚：最高學歷、科系與組別、畢業日期（或預計畢業日）、修過的相關科目學分、已有的考試及格或證照、工作年資、國籍、學歷在哪裡取得。
2. 打開應考資格查詢頁，選考試種類、等級、類科 → 點類科看全文。逐款對照，記下「符合第幾款」。
3. 看「查詢條件外的其他限制」：英檢、證照、工作經驗、體格檢查、年齡。
4. 科系名稱不在列舉內：查應考資格審議釋例，用學校、科系關鍵字找。查不到就寫「建議洽考選部該考試承辦科確認」。
5. 技術類科可能接受「所修課程與應試專業科目 2 科以上名稱相同（每科 2 學分以上）」（115 年高考三級應考須知），要附學分證明或成績單。各考試是否有這條，看該考試應考資格表。

## 四、應試科目、命題大綱與成績計算

### 1. 應試科目的正式依據
- 應試科目寫在各考試規則附表（高普考：附表三高考三級、附表四普考，規則第 4 條），每年應考須知「應試科目及考試日程表」也有。
- 科目修正要在考試前**6 個月**公告；新增類科或減少科目 4 個月前公告；科目名稱含法規名稱的，可隨法規改名隨時修正（施行細則 8 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=R0030002&flno=8 ）。

### 2. 命題大綱怎麼用
1. 命題大綱頁 → 選分頁 → 找考試名稱。查詢日例子：高考三級或相當三等（行政類科）部分專業科目大綱標 115/09/17；技術類科 115/06/25；初等或五等 113/06/26。
2. 先看「適用考試類科一覽表」，再下載該科 PDF。
3. 記下大綱日期，和上一版比：新增的主題標「新增」，刪掉的不再排時數。
4. 專技類大綱常附參考用書，可以直接列成教材清單。
5. 沒有大綱的科目（部分普通科目）：用近 5 年考畢試題整理出題範圍，標「自行整理」。

### 3. 成績計算（公務人員高考三級、普考）
規則第 7 條 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=R0030018&flno=7

| 項目 | 規定 |
|---|---|
| 高考三級純筆試 | 法學知識與英文 14%＋國文 8%＋專業科目平均 78% |
| 普考 | 各科平均 |
| 筆試＋口試、實地測驗 | 依類科比例，例如航空駕駛筆試 70%、口試 30% |
| **不予錄取** | 任一筆試科目 0 分；總成績未滿 50 分；建築設計、藥事行政與法規、景觀與都市設計任一未滿 50 分；口試或實地測驗未滿 60 分 |
| 缺考 | 以 0 分計 → 等於不予錄取 |
| 取位 | 各項取小數 4 位，總成績取小數 2 位（第 3 位四捨五入） |

錄取標準由典試委員會依需用名額決議（規則 8），**不是固定分數**。

### 4. 成績計算（專技）
總成績計算規則 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=R0040006
- 普通科目每科乘 10% 加總，專業科目平均乘剩下的比例（第 4 條）。
- 一科 0 分、專業科目平均不滿 50 分、特定科目未達最低分數，不予及格（第 3 條）。
- 各類科的及格方式寫在各考試規則。例：律師第一試錄取全程到考人數前 33%；第二試依選試科目各取前 33%，但任一科 0 分或國文與選試以外科目合計未滿 400 分不及格；第一試錄取資格不保留（律師考試規則 3、19 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=R0040047&flno=19 ）。

### 5. 測驗題計分（國家考試閱卷規則）
https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=R0020018
- 單選題：答對得分，條文沒有倒扣規定（第 19 條）。
- 複選題：5 個選項、至少 2 個正確；全對得全分；錯 k 個選項得題分的 (5－2k)/5；錯超過 2 個或全未答得 0 分（第 19-1 條）。
- 哪些考試、科目有複選題：看複選題專區當年 PDF。

### 6. 範本：科目配分與優先順序表

| 科目 | 計分比重 | 大綱主題 | 近 5 年出題數 | 我的程度（強／普通／弱） | 優先序 | 預估時數 | 教材章節 | 大綱日期 |
|---|---|---|---|---|---|---|---|---|

優先序原則：比重高 × 出題多 × 程度弱，先排。0 分門檻科目（例如國文作文）不能放棄。

### 7. 常見錯誤
- 看錯類科：同一考試不同類科、高考和普考同名類科，科目與大綱都不同。
- 用舊版大綱或去年的科目表；沒注意 6 個月前公告的科目修正。
- 以為「總分 50 分就錄取」。50 分只是門檻，錄取看名額。
- 把複選題當全有全無計分，結果不敢作答部分選項。

### 2. 網路報名步驟（以 115 年高考三級應考須知為例）
1. 登入國家考試網路報名資訊系統，依系統指示填資料、上傳**最近 1 年內**正面脫帽半身彩色照片（JPG、1MB 內、臉占 70～80%）。
2. 選考區、類科。**報名完成後考區、類科不能改**。
3. 系統提示「免繳報名相關表件」→ 期限內繳費入帳就完成報名。
4. 系統提示「須繳驗報名相關表件」→ 下載列印報名履歷表，附證明文件，**期限內掛號寄出**（郵戳為憑）；逾期或未寄達報名無效、不得補件。

6. 補件通知：依通知期限用郵寄、傳真或電子郵件補正。
7. 考前自行下載列印考試通知書（白色 A4、不得寫字），查試區試場。

115 年高考三級報名費：筆試 1,800 元、筆試＋實地測驗 3,700 元、第二試口試 1,500 元。後備軍人、身心障礙者、原住民族、低收入戶、中低收入戶、特殊境遇家庭可申請報名費**減半**（擇一身分）。116 年金額看當年應考須知。

## 十、歷屆試題與答案

### 1. 國家考試
1. 考畢試題頁選年度（81～115）→ 考試 → 類科、科目，下載試題與答案 PDF。可直接開 `https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?y=西元年&e=考試代碼`（例 y=2023&e=112130）。
2. **有「更正答案」一律以更正答案為準**，一題多個答案都給分的也寫在更正答案裡。
3. 申論題沒有官方解答；複查辦法第 8 條也明定不能要求申論題參考答案。自己寫的標「自行整理，非官方」。
4. 引用考選部網站資料要註明來源、保持完整（考畢試題頁聲明）。

### 2. 技術士
- 學科題庫在測試參考資料頁；頁面聲明學科參考資料**僅供參考，不得做為測試試題或答案依據**。
- 歷屆試題頁聲明：因產業、技術、法令修改，歷屆試題只供參考；試題含他人著作，依著作權法第 54 條引用前要取得同意。

### 3. 著作權
- 依法令舉行的考試試題及備用試題不受著作權保護（著作權法 9 第 1 項第 5 款 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0070017&flno=9 ）。
- 機關、學校辦考試可重製已公開發表著作當試題（著作權法 54 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0070017&flno=54 ）。所以題目裡引用的文章、圖表仍可能有著作權，**不要整份轉貼題組**。
- 補習班解答、講義有著作權，不轉貼；疑義申請也不能只附補習班資料。

## 十二、讀書計畫範本（EX02）

### 1. 倒推時程：算式寫出來
```
可用天數 = 考試首日 − 今天
可用週數 = 可用天數 ÷ 7（取整數）
每週時數 = 平日時數 × 平日天數 + 週末時數 × 週末天數 − 緩衝（每週半天）
總可用時數 = 每週時數 × 可用週數
```
**假設範例**（數字全部是假設）：今天 115/11/07，目標 116 年高考三級筆試首日 116/07/02（期日計畫表預定）。
- 可用天數 237 天 → 33 週
- 平日 3 小時 × 5 天＋週末 6 小時 × 2 天＝27 小時；扣緩衝 3 小時＝24 小時
- 總可用時數＝24 × 33＝792 小時

### 2. 各科分配
```
科目權重 = 計分比重 ×（弱科 1.2～1.3／普通 1.0／強科 0.8）
科目時數 = 總可用時數 × 科目權重 ÷ 所有科目權重合計
```
高考三級純筆試類科：法學知識與英文 14%、國文 8%、專業科目平均 78%。若專業科目有 n 科，每科比重＝78% ÷ n。**n 要看該類科附表三**，不要猜。

| 科目 | 比重 | 程度 | 係數 | 權重 | 分配時數 |
|---|---|---|---|---|---|
| 法學知識與英文 | 14% | | | | |
| 國文 | 8% | | | | |
| 專業科目 1～n | 78%÷n | | | | |

弱科多 20～30% 是卡片規定的做法；係數是一般經驗，不是官方規定。

### 3. 三輪進度（一般經驗）

| 輪次 | 時間占比 | 做什麼 | 完成標準 |
|---|---|---|---|
| 第一輪 基礎 | 約 50% | 依命題大綱讀教材、做筆記 | 每個大綱主題至少讀過一次 |
| 第二輪 題目 | 約 30% | 近 5 年考畢試題、錯題整理 | 每科近 5 年題目做完、錯題入錯題本 |
| 第三輪 衝刺 | 約 20%（最後 4～6 週） | 整份限時模擬、背誦重點、錯題第 3 次以上複習 | 每科至少 2 份完整模擬 |

### 4. 每日任務格式（讀書計畫.md）

| 日期 | 科目 | 大綱主題 | 範圍（頁數或題號） | 預計時數 | 實際時數 | 完成 | 備註 |
|---|---|---|---|---|---|---|---|

### 5. 落後時怎麼重排
1. 算落後比例＝（計畫時數－實際時數）÷ 計畫時數。
2. 超過 20%：先砍低比重、低出題數的主題深度，不砍 0 分門檻科目。
3. 方案 A：週末補時數（不超過使用者說的上限）。方案 B：縮減某章深度、改做題目為主。
4. 重排後寫新的每日任務，舊計畫不刪，標「已調整（日期）」。

### 6. 技術士版
- 大綱用技能檢定規範（工作項目、技能標準、相關知識）。
- 學科：題庫分工作項目做，共用工作項目（90006～90009）別漏。
- 術科：照公告術科試題逐題練，按評分標準自評；實作職類要排場地與材料時間。

### 7. 常見錯誤
- 排到考試前一天都是新進度，沒留模擬與複習。
- 排的時數超過使用者說的可讀時數。
- 考試日期、科目沒有官方來源就排單元（卡片規定只能先做時數盤點）。

## 十三、錯題本與複習排程

### 1. 錯題本欄位（卡片沒規定時用）
```
日期,考試,科目,大綱主題,來源(年度-考試代碼-題號),題型,我的答案,正確答案,答案依據(官方/更正/自行整理),錯因,關鍵觀念,涉及法規條號,下次複習日,複習次數,狀態
```
錯因只用這幾類，方便統計：觀念不懂｜記憶錯｜粗心｜題意誤解｜時間不夠｜修法後答案變。

### 2. 間隔複習（一般經驗，不是官方規定）

| 第幾次 | 距上次 | 做法 |
|---|---|---|
| 1 | 錯的當天 | 寫關鍵觀念 |
| 2 | 3 天後 | 不看答案重做 |
| 3 | 7 天後 | 重做；對了進下一階 |
| 4 | 14 天後 | 重做 |
| 5 | 30 天後 | 對了標「已熟」 |

任何一次又錯，回到第 2 次重新排。

### 3. 每週檢核（EX01 例行任務用）

| 科目 | 計畫時數 | 實際時數 | 落後% | 完成主題 | 本週新增錯題 | 待複習錯題 | 本週已熟 |
|---|---|---|---|---|---|---|---|

最後寫：離考試還有幾天（算式）、目前第幾輪、錯題最多的科目與錯因。

### 4. 常見錯誤
- 只抄題目和答案，不寫錯因與觀念，複習時又錯。
- 錯題用的是補習班答案，官方有更正答案沒改。
- 法律題沒標涉及條號，修法後不知道要改。

## 十四、法規更新追蹤（EX05）

### 1. 步驟
1. 依考試類科與考科列法規清單（應試科目名稱常含法規名稱，例如「行政法」以外，部分科目括號內列法規）。
2. 每部法規打開全國法規資料庫全文頁，記「修正日期」；點「沿革」看修了哪些條。
3. 有修正：整理修正日期、條號、新舊條文、修正重點，**附條文頁網址**。
4. 看施行日：公布不等於施行。例：律師法 114/05/28 修正，頁面註明部分條文最後生效日為 116/1/1。
5. 標記受影響的舊題：錯題本「錯因」改「修法後答案變」，並在歷屆試題統計表備註。
6. 應試科目名稱若因法規改名而變，依施行細則第 8 條可隨時修正，不受 6 個月公告限制。

### 2. 考試以哪一天的法規為準
考選部有沒有「試題涉及法規以考試日前已施行者為準」的明文：**未查證**。作答依據寫「以考選部公告或該次應考須知為準」，查到再附頁面。

### 3. 範本：法規修正追蹤表

| 法規 | 對應考科 | 最新修正日期 | 施行日 | 修正條號 | 修正重點 | 影響的舊題（年度-代碼-題號） | 條文頁網址 | 查詢日 |
|---|---|---|---|---|---|---|---|---|

### 4. 常見錯誤
- 用新聞或補習班整理當修法依據（卡片規定只用全國法規資料庫、立法院、主管機關、考選部）。
- 看到「修正日期」就以為已施行。
- 自己組條文網址導致條號錯。

### 3. 錄取率怎麼算
```
到考錄取率 = 錄取人數 ÷ 到考人數 × 100%
```
數字從考選統計檔或榜單取，寫出年度、考試、類科、分子分母與來源檔。**不預測錄取率**。

`IN-編號｜日期｜類型（官方／新聞／社群）｜重點一句話｜可能影響（推論，寫依據）｜來源網址（公告或文章本身）`

- 用首頁或列表頁當來源網址。
