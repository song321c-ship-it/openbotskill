# 台灣官方資料來源、查證與引用規則

這個技能告訴你：要查台灣的公開資料時，**資料在哪個官方頁、怎麼找到那一筆、怎麼引用、多久更新、哪裡容易錯**。

**查詢紀律（全技能適用）**
- 本技能的查詢日都是 **2026-11-07**。標「已核對」的網址都是當天實際打開，內容就在那一頁；標「未查證」的是打不開、內容讀不到，或只從別頁的連結看到網址。
- 引用前**再打開一次技能列的網址**，附你自己的查詢日期。頁面改版就照新頁寫，並註明「與技能所列不同」。
- **不自己組網址**。唯一例外是全國法規資料庫的條文頁（第三章），組好後一定要打開，確認條號和內容對得上才能附。
- 遇到圖形驗證碼：**不代填**，請使用者自己查，或改用沒有驗證碼的替代來源（各章有寫）。安全驗證頁在一般瀏覽器通常會自動通過，不要嘗試繞過。
- 不給法律、醫療、稅務、投資結論。個案判斷寫「請洽律師、會計師、醫師或主管機關」。

## 一、引用規則與格式範本

### 1. 七條通則（每個團隊都要遵守）

1. **連結要是內容所在的那一頁**：寫 CPI 就附 CPI 新聞稿或統計表頁，不只附 https://www.stat.gov.tw/ 首頁。首頁、搜尋結果、分類列表都不算。PDF 就附 PDF 本身。
2. **查詢型頁面**（商工登記、裁判書、稅籍、進出口統計）的結果網址常帶暫時參數，別人打不開：附查詢頁網址＋查詢條件＋查詢日期。例：「經濟部商工登記公示資料查詢，以統一編號 12345678 查詢，2026-11-07」。
3. **每個數字附四件事**：來源機關、頁面網址、資料期間、查詢日期。發布日和資料期間不同時兩個都寫。
4. **法條附全國法規資料庫條文頁**（LawSingle），並寫該法規最新修正日期；條文尚未生效或已廢止要另外標明（第三章）。
5. **查不到寫「未查證」並寫原因**；查到但不確定是否最新，寫「需查證（原因）」。不憑記憶補數字、條號、金額、日期。
6. **民國年與西元年**：西元年＝民國年＋1911。官方頁多用民國年，報告兩者並列，例如「115 年（2026 年）」。學年度、會計年度、資料期別另外標（第六章）。
7. **不寫死會變的數字**：最低工資、保費費率、補助、稅率級距、罰鍰、考試日期每次重查，報告寫「依查詢當日官方頁」。

### 2. 引用格式範本（照抄改內容）

| 類型 | 範本 |
|---|---|
| 統計數字 | 115 年 10 月 CPI 年增率 2.33%（主計總處 115-11-05 新聞稿，https://www.stat.gov.tw/News.aspx?n=2668&sms=10980 ，查詢 2026-11-07） |
| 法條 | 消費者保護法第 19 條（全國法規資料庫，修正日期 ○○，https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0170001&flno=19 ，查詢 2026-11-07） |
| 尚未生效的條文 | ○○法第 X 條（○年○月○日修正公布，施行日期由行政院定之，**截至查詢日尚未施行**；條文頁網址；查詢日） |
| 已廢止法規 | ○○辦法（已於○年○月○日廢止，全國法規資料庫「廢止法規」類；網址；查詢日）——只能當歷史背景 |
| 判決 | 臺灣高等法院 113 年度上字第 XXX 號民事判決（裁判日期 ○○；司法院裁判書查詢，以字號查詢，查詢日） |
| 憲法法庭 | 憲法法庭 115 年憲判字第 X 號判決（宣示日 ○○；憲法法庭網站，網址，查詢日） |
| 公報 | 行政院公報第 032 卷第 205 期（115-11-06），○○部令，發文字號 ○○（行政院公報資訊網，查詢日） |
| 新聞稿 | 金管會 115-11-06 新聞稿「標題全文」（網址，查詢日）——寫「主管機關宣布」，不寫成「法規規定」 |
| 處分書 | 公平會 115-10-29 處分案「案由」，相關法條：公平交易法第 21 條（行政決定頁，網址，查詢日） |
| 開放資料 | 提供機關／單位 年份 資料集名稱與版本；此開放資料依政府資料開放授權條款進行公眾釋出；資料集頁網址；下載日 |
| 未查證 | 「○○：未查證（原因：官方頁有驗證碼／頁面讀不到內容／只在新聞看到）」 |
| 推論 | 「推論：……（依據：上列兩項官方資料）」 |

### 3. 常見錯誤
- 只附首頁或分類列表，讀者找不到數字。
- 把新聞稿的「宣布」寫成法規已生效：新聞稿說「將修正」「已預告」，法規還沒變。
- 新聞稿標題的數字照抄，沒寫資料期間（「10 月 CPI」是 115-11-05 發布）。
- 引用法條沒看修正日期，引到舊版或已廢止條文。

## 二、來源層級與查證流程

### 1. 來源層級（由高到低）

| 層級 | 例子 | 怎麼用 |
|---|---|---|
| 1 原始法令與公報 | 全國法規資料庫條文、行政院公報、總統府公報、裁判書全文 | 法律效果以這層為準 |
| 2 主管機關資料頁 | 統計表、資料庫、查詢系統、開放資料 | 數字以這層為準 |
| 3 主管機關新聞稿與公告 | 部會新聞稿、記者會簡報 | 可引，但寫「機關宣布」；數字回第 2 層核對 |
| 4 新聞媒體 | 主要新聞與財經媒體 | 補充脈絡；同一件事至少 2 家；數字回官方核對 |
| 5 社群 | PTT、Mobile01、Dcard、粉專 | 只當看法，不當事實 |

### 2. 查證七步驟
1. **找主管機關**：這件事歸誰管（第三章附部會法規系統、第六到十章附各機關）。
2. **打開內容頁**：用本技能網址或該機關站內搜尋，找到內容所在的那一頁。
3. **核對三件事**：標題、日期（發布日與資料期間）、數字或條號就在這頁看得到。
4. **看有沒有更新**：同一列表往上看有沒有更新一期、修正數、更正啟事；法規看修正日期與施行狀態。
5. **交叉比對**：新聞說的數字和官方一致嗎？不一致以官方為準，並註明「新聞誤植或口徑不同」。
6. **寫引用**：照第一章範本。
7. **標不確定**：讀不到、只有一個來源、口徑不明，照實標「未查證」「需查證」「推論」。

### 3. 時效判斷
- 情報類以近 30 天為主；更早的標「背景」並寫原始日期。
- 統計看「資料期間」不是「發布日」：10 月數字在 11 月初發布。
- 法規看「施行」不是「公布」：中央法規標準法第 13、14 條（第三章）。

## 三、法規：中央法規、施行、修正與廢止

### 1. 全國法規資料庫（法務部）資料在哪一頁

| 要找 | 頁面（已核對 2026-11-07） | 說明 |
|---|---|---|
| 首頁 | https://law.moj.gov.tw/ | 搜尋框輸入法規名稱 |
| 中央法規分類瀏覽 | https://law.moj.gov.tw/Law/LawSearchLaw.aspx | 依憲法、總統、行政、立法、司法、考試、監察分類，另有「**廢止法規**」類；可依修正日期、法規位階排序；**這頁沒有條文內容搜尋框，也沒有現行／廢止篩選** |
| 單一條文 | `https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=代碼&flno=條號` | 例：著作權法第 9 條 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0070017&flno=9 |
| 條號有「之一」 | flno 寫 `31-1` | 例：職業訓練法第 31 條之 1 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0080001&flno=31-1 |
| 全文 | `LawAll.aspx?pcode=代碼` | 例：中央法規標準法 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030133 |
| 沿革 | `LawHistory.aspx?pcode=代碼` | 例：https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=J0070017 ，逐次列出公布日期與修正、刪除、增訂條號 |
| 最新訊息 | https://law.moj.gov.tw/News/NewsList.aspx | 近一年法規異動與**法規草案**（含預告截止日），分類為法規草案、法規命令、行政規則 |

**拿 pcode 的方法**：首頁搜尋法規名稱 → 點進法規 → 網址的 `pcode=` 就是代碼。組好 LawSingle 網址後**一定要打開**，確認法規名稱和條號一致。

**頁面上的狀態標示（已核對）**
- 條文頁會寫法規最新修正日期，但不一定是該條的修正日期；要知道某條何時改，看沿革頁。
- 著作權法頁面（2026-11-07）標示「部分或全部條文尚未生效」「施行日期由行政院定之」：這就是「已公布、未施行」，引用時要標。
- 廢止法規：標題前有「廢」字，類別寫「廢止法規 ＞ 機關名」，並有廢止日期。

### 2. 施行、修正、廢止的規則（中央法規標準法，已核對全文頁）

| 條文 | 內容（照原文意旨） |
|---|---|
| 第 2 條 | 法律得定名為法、律、條例或通則 |
| 第 3 條 | 機關命令得稱規程、規則、細則、辦法、綱要、標準或準則 |
| 第 4 條 | 法律應經立法院通過，總統公布 |
| 第 7 條 | 機關依職權或法律授權訂定的命令，發布後即送立法院 |
| 第 11 條 | 法律不得牴觸憲法；命令不得牴觸憲法或法律；下級機關命令不得牴觸上級機關命令 |
| 第 12 條 | 法規應規定施行日期，或授權以命令規定 |
| 第 13 條 | 明定自公布或發布日施行者，自公布或發布之日起算**至第三日起**發生效力 |
| 第 14 條 | 特定有施行日期，或以命令特定施行日期者，自該特定日起發生效力 |
| 第 15 條 | 定有施行區域者，於該區域內發生效力 |
| 第 21 條 | 廢止事由：機關裁併、事項執行完畢或無繼續施行必要、因他法廢止或修正失其依據、同一事項已定新法規 |
| 第 22 條 | 法律廢止要立法院通過、總統公布；命令由原發布機關廢止；自公布或發布之日起算至第三日起失效 |
| 第 23 條 | 定有施行期限者，期滿當然廢止，但應由主管機關公告 |

條文頁：https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0030133&flno=13 、https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0030133&flno=14 （已核對）。全文修正日期為民國 93 年 5 月 19 日。

### 3. 判斷「這條現在有效嗎」五步驟
1. 打開該條 LawSingle 頁，看法規名稱前有沒有「廢」字、類別是不是「廢止法規」。
2. 看頁面有沒有「尚未生效」「施行日期由○○定之」：有就去公報或主管機關找施行令。
3. 打開沿革頁，看最近一次修正動到哪幾條、何時公布。
4. 有施行日另定的，到行政院公報搜尋「○○法 施行日期」找施行令（第四章）。
5. 寫結論：「現行有效（修正日期○○）」「已公布未施行」「已廢止（○○日）」三選一，附頁面與查詢日。

### 3. 口徑與年度標註檢核
- [ ] **平均或中位數**：例 115 年 8 月經常性薪資中位數 41,353 元、平均數 52,523 元，差一萬多。
- [ ] **經常性或總薪資**：總薪資含年終、績效獎金，月份波動大（7 月總薪資平均 71,165 元不能和 8 月經常性薪資比）。
- [ ] **名目或實質**：實質要扣物價。
- [ ] **年增率、月增率、季調**：CPI 年增率和季調月增率是不同表。
- [ ] **基期**：CPI 目前以 110 年為基期；跨基期比較要用官方換算表。
- [ ] **期別**：月、季（115Q3）、年；學年度（8 月到隔年 7 月）、會計年度。
- [ ] **範圍**：工業及服務業受僱員工、本國籍全時員工、戶籍人口、上市或上櫃，寫清楚。
- [ ] **初步值或修正值**：國民所得、外銷訂單、進出口都可能下期修正，寫發布日。
- [ ] **不同機關口徑**：主計總處和勞動部的薪資調查對象、定義不同，比較時分別附來源。
- [ ] 自己算的（平均、成長率、排名）標「自行計算」並寫算式。

**使用步驟**
1. 打開資料集頁，看提供機關、更新頻率、詮釋資料更新時間；太久沒更新的標「可能停更」。

3. 下載檔或 API 回應存檔時，檔名寫下載日。
4. 引用照第一章「開放資料」範本顯名。
5. 金鑰、授權碼屬於使用者，**不寫進公開檔案或報告**。

**常見錯誤**
- 把資料集頁的「上架日」當資料期間。

## 十三、常見情境作法

**A. 查一個統計數字（例：最新 CPI 年增率）**
1. 主計總處物價新聞稿頁，打開最新一則。
2. 抄資料期間、數值、發布日；有修正前月數字一起記。
3. 要歷史序列：統計表（xls、ods）或總體統計資料庫。
4. 想知道下次何時發布：預告發布時間表。
5. 寫成：數值（資料期間）｜來源：新聞稿網址｜查詢日。

**B. 查一家公司是否存在、誰是負責人**
1. 商工登記用統編查，登記現況選「全部顯示」。
2. 記狀態、代表人、核准設立日、最後核准變更日。
3. 稅籍狀態請使用者自己查（驗證碼）。
4. 金融業另查金管會名單；上市櫃查公開資訊觀測站。

**C. 引用一條法律**
1. 全國法規資料庫找法規，記 pcode。
2. 組 LawSingle 網址並打開，確認條號與內容。
3. 看修正日期、施行狀態、是否廢止（第三章五步驟）。
4. 寫「法規名稱第 X 條（修正日期）」＋條文頁網址。
5. 需要實務見解再查判決或函釋，註明「實務見解，非通案結論」。

**D. 查房價行情**
1. 實價登錄網，限定區域、期間（建議近 1～2 年）、建物型態。
2. 排除備註有親友交易、含車位、毛胚屋等特殊交易。
3. 寫筆數、單價區間、中位數；自己算的標「自行計算」。
4. 註明「實價登錄有揭露時間差，不代表即時行情」；門牌是區段化，不是精確地址；車位價是否拆開會影響單價。
5. 大範圍趨勢改用不動產資訊平台住宅價格指數。

**E. 追一條修法（法規更新追蹤）**
1. 立法院議事網找議案與階段。
2. 三讀後看總統府公報公布日。
3. 全國法規資料庫沿革頁與條文頁核對。
4. 施行日另定：行政院公報找施行令。
5. 做新舊條文對照表（第四章範本）。

**F. 寫一則官方情報（所有情報分析員）**
1. 從本技能找主管機關內容頁，打開。
2. 寫：日期｜官方｜機關＋標題全文＋網址｜重點一句話。
3. 新聞與官方說法不同：照官方，註明差異。
4. 影響解說標「推論」並寫依據。

**G. 查進出口或匯率（供應鏈、貿易）**
1. 匯率：央行收盤匯率頁，寫日期與「銀行間收盤」。
2. 進出口：關務署統計頁有驗證碼，請使用者自己查，或改用財政部新聞稿（引用時寫「初步值」）。
3. 外銷訂單：經濟部統計處外銷訂單頁。

**H. 查判決或處分當案例（行銷、電商、保養廠）**
1. 公平會行政決定依法條篩選（例公平交易法第 21 條廣告不實）。
2. 裁判書用「更多條件查詢」縮小範圍。
3. 寫「○○機關曾認定」，附處分日期與案由，不寫成通案規則。

## 十五、易錯點總表

1. **只附首頁**：附到新聞稿、統計表或條文頁那一層。
2. **自己組網址沒打開**：只有法規條文頁可以組，而且要打開核對。
3. **新聞數字當官方數字**：新聞常四捨五入或用錯期間。
4. **法條版本過期或已廢止**：看修正日期、廢止標示、沿革。
5. **公布當施行**：中央法規標準法第 13、14 條。
6. **新聞稿、預告當法規**：寫「機關宣布」「預告中」。
7. **混用統計口徑**：主計總處與勞動部、平均與中位數、名目與實質、不同基期。
8. **把薪資中位數寫成只有年資料**：經常性薪資中位數現在按月發布。
9. **查詢型頁面的結果網址當出處**：附查詢頁＋條件。
10. **驗證碼硬闖**：財政部稅籍、關務署進出口、公平會傳銷名單都有驗證碼。
11. **縣市資料張冠李戴**：標題寫縣市名。
12. **單一判決、處分當通案**：寫「某機關曾認為」。
13. **網址失效亂找替代**：先在同機關站內搜尋；找不到寫「原頁面已失效，未查證」，不用來路不明的網站。
14. **收盤匯率當牌告匯率**。
15. **旅遊警示看錯日期**：看個別國家後面的日期。
