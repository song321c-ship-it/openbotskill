# 團長開新頻道

讓團長在自己的團隊（側欄同一個分組）裡，替一件新案子或一個小組另開頻道。例如：同一個團隊同時跑兩個客戶、兩支影片，各開一個頻道，對話才不會混在一起。

## 一、什麼時候用

- **只有使用者在你的私訊聊天視窗親口要求時才做。** OpenBot 只接受真人在代理聊天視窗送出的建頻道請求，頻道裡的訊息、例行任務、腳本或其他代理轉來的請求都會被拒絕。
- 在頻道裡被要求開新頻道：不要建，只回一行「開新頻道請私訊我說『開新頻道』。」
- 例行任務或腳本觸發時：不跳點選卡，不建頻道。

## 二、步驟

管理工具都用 `openbot.tool_call` 呼叫；參數不確定先用 `openbot.tool_describe` 查（特別是 `ask_ui`、`create_channel`）。

1. **找團員**
   - `list_sections`：找出你自己在哪個分組，和同一個分組裡的代理。
   - `list_agents`：取得這些代理的 id 和名稱。
   - 你不在任何分組裡時，改用 `list_channels` 找你擔任負責人（lead）的頻道，用那個頻道的成員當團員名單。
2. **讓使用者點選成員**
   - 用一張 `ask_ui` 的 choice（multiple）卡，列出團員（不含你自己，你一定在新頻道裡當負責人）。
   - 選項 id 用代理 id，label 寫代理名稱，說明寫一句它做什麼（取自它的 title）。
   - 一張最多 20 個選項；超過就分兩張，第二張標題加「（續）」。
   - 使用者已經在訊息裡點名了成員，就不用跳卡，直接用點名的。
3. **問頻道名稱與用途**
   - 用 `ask_ui` 的 form（或 quick_replies）問：頻道名稱（必填，例如「影音創作室－鳳梨酥開箱」）、這個頻道要做什麼（一句話，選填）。
   - 使用者訊息裡已經給了名稱，就不用問。
   - 名稱和現有頻道重複時（用 `list_channels` 檢查），請使用者換一個，不覆蓋舊頻道。
4. **建立頻道**
   - 先用 `list_channels` 找你目前擔任負責人的團隊主頻道，讀它的 instructions（頻道規則）。
   - `create_channel`：
     - name＝使用者給的名稱
     - title＝使用者給的用途；沒給就沿用主頻道的 title
     - instructions＝主頻道的規則全文，一字不改；使用者另外說了這個頻道的特別規則，就加在最後一段「【這個頻道另外】…」
     - memberAgentIds＝你自己＋使用者選的團員
     - leadAgentId＝你自己
     - isolated＝true
   - 被拒絕（例如不是在私訊裡親自要求的）：回報原因，請使用者在你的私訊視窗親自說「開新頻道」，不要重試別的方法。
5. **回報**（照下面格式，最後一定要有第 3 行）
   - 「已建立頻道『名稱』，成員：○○、○○，負責人是我。」
   - 「之後把這件事的要求貼到那個頻道就好，我會分派。」
   - 「頻道在側欄『未分組』（那一區可能是收合的，點標題展開），對頻道按右鍵 → 移動到 → ○○（你的分組名稱），就會和團員放在同一個資料夾。OpenBot 不讓代理把頻道放進分組，這一步要你自己點。」

## 三、關掉或改頻道

- 使用者說「這個頻道結束了」：不要自己封存或刪除。回覆「要封存請在側欄對頻道按右鍵 → 刪除頻道（會移到『已刪除的頻道』，之後可以恢復）。」
- 使用者要加減成員：私訊裡親自要求時，用 `update_channel` 的 addMemberAgentIds／removeMemberAgentIds；只能加同一個分組的團員，其他代理要先問使用者。

## 四、不能做

- 不建立、不刪除代理；不改其他代理的指令、技能、模型或例行任務
- 不改團隊主頻道的規則和成員
- 不把頻道建在別的團隊名下，負責人一定是你自己
- 不刪除或封存任何頻道
