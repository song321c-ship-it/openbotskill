# 個股深度研究（台股＋美股）

報告要讓一般投資人看完就知道：這家公司**在做什麼、靠什麼賺錢、跟誰競爭、強在哪、現在的價格跟同業和自己過去比起來怎樣、有什麼風險**。寫得詳細、每個數字查得到出處，但**不替使用者做決定**。

## 一、硬規則（先讀）

1. **不給評等、不給目標價、不判斷進出場時機**。不寫「買進／持有／賣出」「值得買」「被低估所以該買」。可以寫「本益比低於同業中位數」，不能寫「所以便宜、可以買」。
2. **每個數字附來源網址與資料期間**（例如「2025 年報」「2026 Q2 單季」「2026-11-05 收盤」）。網址必須是這次實際打開、看得到那個數字的頁面。公開資訊觀測站用 POST 介面取得的數字，另外寫一般人點得開的查詢頁和要選的條件（例如「公開資訊觀測站 → 財務比較 e 點通 → 財務比率分析，公司代號 2330、年度 114」），讓讀者自己查得到。
3. **查不到就寫「未取得」**，絕不用記憶或印象補數字；同一張表裡有缺值，就在表下寫缺什麼、為什麼缺。
4. **開工前先確認今天日期與最新財報期間**：台股看公開資訊觀測站最近一季財報是否已公告；美股看 SEC 最新 10-Q／10-K 的期間。報告開頭寫「資料截至 YYYY-MM-DD，最新財報為 XXXX」。
5. **比率一律用 Python 算**，報告裡寫出算式（分子、分母、期間）。不心算、不抄別的網站算好的比率（官方公布的除外，並註明）。
6. **判讀標「推論」並寫依據**；看不出結論就寫「資料不足以判斷」。
7. 公司一律寫「名稱（代號）」；同業也一樣。

**常用 XBRL 標籤**（us-gaap）：
- 營收：`Revenues`；2022 年以前常見 `RevenueFromContractWithCustomerExcludingAssessedTax`，兩個都要找

- 營業利益：`OperatingIncomeLoss`

## 三、報告章節（照這個順序寫，每節都要有）

### 0. 摘要
- 一句話：這家公司是什麼
- **5 個重點**（各一句，含數字）
- 資料截至日期、最新財報期間、資料完整度（缺了哪些）
- **名詞小抄**：報告用到的 ROE、營益率、本益比、股價淨值比、自由現金流、中位數、四分位數，各用一句白話解釋

### 1. 公司 101
- **產業**：台股寫觀測站產業類別；美股寫 SIC 與公司在 10-K 的自我描述
- **主營業務**：產品或服務、主要客戶類型（照年報或 10-K 原文整理）
- **營收結構**：依產品、地區、客戶的比例（附期間）；前幾大客戶占比（年報有揭露才寫）
- **商業模式**：怎麼賺錢（賣產品、授權、訂閱、代工……），一兩句

### 2. 產業與競爭
- **產業概況**：成長性、景氣循環性、主要驅動因素（有來源才寫數字，其餘標推論）
- **主要競爭者 5～10 家**：名稱（代號）、在哪個市場或產品線競爭、規模對照（營收）。來源：10-K Competition 小節、年報「市場及產銷概況」
- **市占率**：只有官方、公司揭露或可查證的研究機構數字才寫，附來源；沒有就寫「未取得可查證的市占資料」

### 3. 護城河（推論，要有證據）
從五類找證據，每類寫「有／沒有／看不出來」與依據：

| 類型 | 可以拿來佐證的數據或事實 |
|---|---|
| 無形資產（品牌、專利、執照） | 毛利率長期高於同業、定價能力、專利或特許執照 |
| 轉換成本 | 客戶長期合作、產品深度嵌入客戶流程 |
| 網路效應 | 使用者越多價值越高 |
| 成本優勢 | 規模、製程、地理位置帶來的單位成本較低；營益率高於同業 |
| 規模效率 | 市場小到只容得下少數業者 |

最後一行：「綜合看，護城河可能為 寬／窄／看不出來（推論）」，並寫最主要的 2 個證據。**長期 ROE 或毛利率持續高於同業中位數，是護城河最重要的數字證據**；只有一兩年高不算。

要用這個證據，就在本節附一張**逐年對照表**：近 5 年本公司與同業中位數的毛利率、ROE 各一列。報告裡引用的表名（例如「表 F」）一定要真的存在於報告中，不能只寫在腦中。

### 4. 同業比較（核心）

**選同業**（借鏡同業比較的通用做法）：
- 3～6 家，**寧可 3 家精準，也不要 6 家勉強**
- 條件：商業模式相近 → 同產業分類 → 規模相近（營收差距 10 倍以內優先）→ 同市場優先
- 不納入：集團控股公司、陷入財務困境的公司、還沒有營收的公司、財報期間差太多的公司
- 同業近四季虧損，或近四季獲利主要來自一次性收益（處分資產、業外利益），它的**本益比寫「不適用」，不算進本益比中位數**；其他比率照常列。被排除的要在表下寫明。判斷方法：近四季淨利高於營業利益時，查 XBRL 的 `GainLossOnSaleOfBusiness`、`GainLossOnInvestments`、`IncomeLossFromDiscontinuedOperationsNetOfTax` 和 10-Q 附註，寫出金額與出處；不要停在「可能含一次性項目」
- 找不到營收差距 10 倍以內的同業時（例如 產業龍頭），寫明「同業規模差距大，比較僅供參考」
- 台股可以混入美股或其他市場的主要對手（例如 台積電 對 英特爾、三星），但要寫明幣別、會計準則不同
- 寫出每家入選的理由一句

**比較表**（同一期間、同一來源）：

| 指標 | 本公司 | 同業 A | 同業 B | 同業 C | 同業中位數 | 第 1～3 四分位 | 本公司 − 中位數 |
|---|---|---|---|---|---|---|---|

指標 8～10 項：營收年增率、毛利率、營業利益率、淨利率、ROE、ROA、負債比、流動比率、本益比、股價淨值比、現金殖利率。

- **同業統計用中位數與四分位數，不用平均**（百分比指標一兩家極端值就會把平均拉歪）
- 證交所月報的官方「產業類股平均本益比」另外並列，標明是平均、不是中位數
- 判讀：「毛利率 59%，高於同業中位數 45% 約 14 個百分點，可能反映製程領先帶來的定價能力（推論）」

### 5. 歷年比較
- 列**近 5 年**（有 10 年更好）年度表：營收、營收年增率、毛利率、營益率、淨利率、EPS、ROE、負債比、營業現金流、自由現金流
- 台股另列**近 8 季單季**表（觀測站季資料是累計數，要相減成單季）
- 每項算「自身 5 年中位數」，最新一年和它比：
  - 高於中位數且近 3 年逐年上升 → 「改善」
  - 低於中位數且近 3 年逐年下降 → 「轉弱」
  - 其他 → 「持平或波動」
  - **越低越好的指標要反過來判**：負債比、資本支出占營收比（看用途）、存貨週轉天數、應收帳款週轉天數；例如 負債比低於自身中位數且逐年下降 → 「改善」
- 判讀要說原因（看 MD&A 或年報「營運概況」怎麼解釋），找不到原因就寫「年報未說明」

### 6. 估值
- 目前本益比、股價淨值比、殖利率（附日期）。XBRL 沒有股利標籤時，查 10-K Item 5 或年報的股利政策：不發股利寫 0%，不寫「未取得」。近四季內股利政策大改（例如 季配息提高好幾倍），另列「最新一季年化殖利率」，並在判讀提一句
- **三個比較**：和同業中位數比、和證交所產業平均比、和自己近 5 年的區間比（最低、中位數、最高；台股用 BWIBBU 逐月資料）
- 一句話寫「獲利表現撐不撐得起目前的估值」（推論），例如「本益比高於自身 5 年中位數，但 ROE 與營收成長也在 5 年高檔，兩者大致相稱（推論）」
- 不算內在價值、不給目標價

### 7. 風險（8～12 項，分四類）
1. **產業與競爭**：技術被取代、新進者、價格戰
2. **營運**：客戶或供應商集中、產能、關鍵人物
3. **財務**：負債、匯率、資本支出壓力、現金流
4. **法規與地緣**：出口管制、關稅、環保、訴訟

每項一句說明，附出處（10-K Item 1A、年報風險事項，或新聞）。

### 8. 綜合判讀（不給評等）
- **強項 3 點、弱項 3 點**（都要對應前面章節的數字）
- **接下來值得追蹤的 3～5 個指標或事件**（例如 下一季毛利率、某客戶訂單、某法規）；並提醒使用者可以對個股哨兵說「追蹤 代號」
- 最後一句固定：「這是研究整理，不是投資建議；是否投資由你決定。」

### 9. 資料來源
逐條列出用到的網址與資料期間、取得日期。

## 四、公式

| 指標 | 公式 | 注意 |
|---|---|---|
| 毛利率 | 毛利 ÷ 營收 | |
| 營業利益率 | 營業利益 ÷ 營收 | |
| 淨利率 | 歸屬母公司淨利 ÷ 營收 | 台股用「歸屬於母公司業主」 |
| ROE | 歸屬母公司淨利 ÷ 平均股東權益（期初＋期末）÷ 2 | 只有期末數時寫「用期末權益」 |
| ROA | 淨利 ÷ 平均總資產 | |
| 負債比 | 總負債 ÷ 總資產 | 金融業不適用 |
| 流動比率 | 流動資產 ÷ 流動負債 | |
| 自由現金流 | 營業現金流 − 資本支出 | |
| 本益比 | 股價 ÷ 近四季 EPS | 證交所 BWIBBU 的本益比是官方算法，直接引用並註明 |
| 營收年增率 | 本期營收 ÷ 去年同期營收 − 1 | |
| 年複合成長率 | （期末 ÷ 期初）^(1 ÷ 年數) − 1 | |

## 五、特殊情況

- **金融業**（銀行、保險、證券）：負債比、流動比不適用；改看 ROE、ROA、逾放比、資本適足率、淨利差（銀行），並寫明
- **虧損年度**：本益比寫「不適用（虧損）」，改看股價淨值比、股價營收比；歷年本益比中位數排除虧損年度並註明
- **會計年度和日曆年不同**：例如 NVIDIA 的會計年度約在 1 月底結束；表頭寫「FY2026（截至 2026-01）」，和同業比時對齊最接近的期間並寫明。「最接近」看財年截止日相差幾天（可早可晚），不看 FY 編號：例如 輝達 FY2026（至 2026-01-25）配高通 FY2025（至 2025-09-28，差 4 個月），不配高通 FY2026（至 2026-09，差 8 個月）。逐年表要註明每家同業實際用的截止日
- **ADR 與本地股**：例如 台積電 ADR（TSM）1 單位＝5 股普通股；兩者的本益比、殖利率要分開寫，不要混算
- **幣別**：跨市場比較只比比率，不直接比金額；要比規模時寫出換算匯率與日期
- **一次性損益**：處分資產、匯兌、訴訟和解造成某年淨利特別高或低，要標出並寫「排除一次性項目後」的看法（有揭露才排除）

## 六、合理區間檢查（交出前）

數字超出下面範圍時，回頭確認是否抓錯欄位、單位（仟元／百萬／美元）、期間或幣別：
- 毛利率 −50%～100%；淨利率 −100%～80%
- ROE −100%～150%（極高通常是股東權益很小或為負，要註明）
- 負債比 0%～100%（金融業除外）
- 本益比 0～200；超過 200 或負值寫「不適用」並說明
- 營收年增率超過 ±100% 要寫原因（併購、基期低）

## 七、易錯點

- 用記憶寫營收、市占、競爭者：一律要有這次打開的來源，沒有就寫「未取得」。
- 台股季資料當單季：觀測站彙總表是累計數，要相減。
- 同業用平均：百分比指標要用中位數，平均只能用在官方公布的產業平均本益比並註明。
- 同業期間不一致：本公司 2026 Q2、同業 2025 年報混在同一張表，要對齊或註明。
- 把「本益比低於同業」寫成「便宜可以買」：只能描述差距並說可能原因（成長較慢、風險較高、市場低估都有可能）。
- 只寫好話：強項與弱項都要 3 點，風險至少 8 項。
- XBRL 營收標籤只找一個：2022 年前後標籤不同，會漏掉早年資料。
- 網址自己組：觀測站與 SEC 的網址要用這次實際打開的，不要憑印象拼。
