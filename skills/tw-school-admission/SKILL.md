# 台灣升學制度速查（國中升學＋大學與技專升學）

這個技能教你：**去哪查、穩定規則是什麼、116 學年度官方日程、怎麼算、怎麼檢查、哪裡容易錯**，並附可直接套的表格。

你給的是**資訊整理、試算與檢核草稿，不是錄取保證**。不替學生報名、繳費、填志願、聲明放棄；志願由學生和家長決定。

**查詢紀律**（全技能適用）
- 本技能所有網址的查詢日都是 **2026-11-07**（民國 115 年 11 月 7 日）。標網址的內容都是當天實際打開、在那一頁或那份 PDF 看得到。標「未查證」的是頁面沒寫、讀不到，或只在新聞與學校轉貼看到。
- 寫「116 學年度」的日期與規則，都來自官方頁面明寫 116 學年度的文件；**117 學年度以後要重新查**。其他會變的東西（各區比序配分、校系採計科目、篩選倍率、名額）只寫去哪查。
- 引用前**再打開本技能列的頁面核對一次**；頁面改了照新頁寫並說明不同。簡章有「修正事項」或「修正對照表」時，以最後公告為準。
- 甄選會（cac.edu.tw）的簡章 PDF 要從該頁面點開，直接貼 PDF 網址可能打不開；打不開時寫「請從○○頁點選開啟」，不要憑記憶補數字。
- 學生只寫暱稱；不記身分證字號、准考證號碼、密碼、學校班級座號。使用者貼出來時寫成 ***。

## 五、免試入學與超額比序

### 1. 穩定規則（ttk.entry.edu.tw 全國委員會說明）

| 規則 | 內容 |

| 兩大方式 | 高級中等學校入學整合成「免試入學」與「特色招生入學」 |
| 不考試 | 免試入學不加考入學測驗，**不採計國中在校期間考試評量成績**（健康與體育、藝術、綜合活動、科技四領域除外） |
| 就學區 | 全國 15 個就學區，以直轄市、縣（市）劃分；原則上只能選所屬就學區學校；交界學校可劃入「共同就學區」 |

- 忘了查同分比序順序，只算總分。
- 共同就學區學校以為一定能跨區填。

## 十七、常見情境的作法步驟

### 情境 1：超額比序試算（JH03）
1. 確認就學區與學年度，下載當學年度簡章（含修正對照表）。
2. 填第五章「比序規則抄錄表」，每列附頁碼。
3. 填學生資料：多元學習表現各子項（採計截止日前的紀錄）、會考成績（模擬考標「預估」）。
4. 逐項計分，超過上限的子項截到上限。
5. 志願序情境：同一校放不同位置各算一次。
6. 對照歷年錄取參考（委員會或國中端公告），配分有改的年度不能直接比。
7. 輸出：表格列各項積分、總分、差距，寫「試算，非錄取保證，以委員會分發結果為準」。

### 情境 2：學系選擇對照（CE02、CE03）
1. 盤點興趣、擅長科目、高中修課（加深加廣）、多元表現。
2. 用 ColleGo! 找 2～3 個學群，列學類與校系。
3. 抓校系分則：繁星（排名門檻、檢定）、申請（檢定、倍率、二階、審查代碼、甄試日）、分發（採計、加權）。
4. 對照落點：學測級分 vs. 當年五標；申請看近年篩選結果（甄選會篩選結果查詢）；分發看考分會最低錄取標準。
5. 分三層：夢想、目標、保底，寫判斷依據；申請六個校系建議三層都有。
6. 檢查衝突：甄試撞期、審查資料負荷、繁星與申請限制、特殊選才報到限制。
7. 輸出校系對照表，每欄附來源與學年度，寫「落點為推論，依歷年資料，非錄取保證」。

### 情境 3：整理年度時程（JH05、CE06）
1. 國中：會考與適性入學重要日程表＋各區簡章＋五專日程。
2. 大學：大考中心試務日期＋甄選會繁星、申請日程＋考分會分發日程＋技專各管道日程。
3. 用第十四章欄位，民國西元並列；「錯過就失去資格」的列放前面並粗體。
4. 簡章有更正公告時更新，舊列保留並標「已更正」。

### 情境 4：家長問「哪條路比較好」
- 列各管道條件、優缺點、時程與互相的限制，讓家長自己決定。
- 一定提醒錄取後放棄的規定與對後面管道的影響（例：繁星第一至七類錄取不得報申請；申請錄取未放棄不得參加分發與四技聯登）。

### 情境 5：成績出來後的 72 小時（CE01）
1. 學測成績（116/2/25）出來當天：填成績.csv，對當年五標。
2. 隔天：落點分析師與科系探索同時開工；申請六校系候選拉到 10 個。
3. 第三天：刪到 6 個，檢查撞期與審查資料，確定 3/23～3/24 報名。

## 十八、交付前檢核表

- [ ] 每個日期、名額、配分、倍率都附來源網址、學年度、查詢日期

## 十九、常見錯誤總表

| 錯誤 | 正確 |
|---|---|
| 跨年度混用配分、倍率、校系數 | 每年查當年度簡章 |
| 跨區混用比序 | 只用學生所屬就學區 |
| A++ 是等級 | 是精熟等級上的標示 |
| 英語標示加在閱讀 | 加在英語整體等級 |
| 分科七科 | 116 起八科（加數學乙） |
| 15 級分×4＝60 級分 | 看大考中心公布的 60 級分 |
| 五標是平均 | 是第 88、75、50、25、12 百分位數 |
| 繁星第一至七類錄取放棄後可報申請 | 無論放棄與否都不得報名 |
| 申請只錄取一校系不用登記 | 一律要登記就讀志願序 |
| 分發只看分科 | 學測、分科、術科都可採計，分科至少 1 科 |
| 最低登記標準用加權分 | 用未加權級分加總 |
| 四技申請入學看統測 | 四技申請入學看學測；甄選入學看統測 |
| 統測五科全考 | 116 起自主選考 |
| 甄選入學 4 倍 | 117 起才 4 倍 |
| ColleGo! 是教育部的 | 主辦招聯會 |
| ttk.entry.edu.tw 只是基北區 | 查詢日是 116 全國免試入學委員會頁，基北區入口預計 11 月底上線 |
| 錯過報名再補 | 各管道報名、繳費、登記、放棄都有期限，錯過即失去資格 |
| 採計科目看錯（例：只看檢定沒看倍率科目） | 檢定、倍率、採計三欄分開抄 |
